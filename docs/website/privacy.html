隐私政策 (Privacy Policy)

最后更新日期：2026年11月11日

快发布 (OpenPub) 是一款专为创作者打造的多平台内容分发工具。我们深知账号安全与数据隐私对您的重要性，本应用在设计之初就遵循 “绝对本地化” 的核心原则。

1. 我们收集什么信息？

我们不收集、不读取、不上传任何您的个人身份信息或账号密码。

您在各平台的登录状态（Cookie/Token）、文章草稿以及图片等数据，均完全保留在您的本地计算机硬盘中。部分敏感的登录凭据会通过操作系统级的底层加密（如 Windows 的 DPAPI）进行安全存储。

2. 数据流向与第三方服务

  • 内容分发机制：当您执行“同步”或“发布”操作时，快发布通过内置的 Webview 沙盒环境，直接将您的内容发送至目标平台（如头条、知乎、小红书、B站等）的官方服务器。本软件仅作为通道，绝不将内容备份至任何第三方服务器。
  • 图片与静态资源：分发过程中涉及的图片会自动转存至目标平台的官方图床，不会经由快发布的中转服务器。
  • 版本更新：应用可能通过获取公开的开源仓库接口来检查是否有新版本，此过程不包含任何个人身份信息。

3. Webview 技术声明

为了绕过部分平台对纯 API 请求的严苛限制并保持登录态的稳定，快发布使用了基于系统原生内核的 Webview 技术。Webview 运行在完全隔离的沙盒中，您的所有页面操作、授权及验证码输入行为，均在您的本地机器上完成。

4. 您的权利

  • 数据删除：您可以随时在软件内部点击“清除数据”或“退出登录”，这会立刻抹除本地存储的加密 Cookie。
  • 彻底卸载：卸载本软件后，您在应用数据目录（如 %LOCALAPPDATA%\com.openpub.desktop）下的所有 Webview 缓存和本地凭据将被一同清理。
